# Debug 測試版本說明

GitHub Release 提供的 APK 為開發階段使用的 Debug 測試版本，目的在於確認操作流程、版面、主題及裝置相容性，不代表正式發行品質。

## 版本性質

- Release 類型：Pre-release
- 建置類型：Debug
- 簽署方式：Android 開發用 Debug 簽章
- 用途：功能預覽、測試與意見回饋
- 不建議用途：正式比賽、重要活動或長期資料保存

## 安裝注意事項

1. 從本專案的 GitHub Releases 下載 APK。
2. 確認 Release 頁面有標示 **Pre-release** 與 **Debug 測試版**。
3. Android 若出現安全提醒，請確認 APK 確實下載自本專案公開 Release。
4. 必要時允許目前使用的瀏覽器或檔案管理器安裝未知應用程式。
5. 安裝完成後，建議立即關閉該來源的未知應用程式安裝權限。

## 與正式版本的差異

- Debug APK 未經過正式 Release 金鑰簽署。
- Debug APK 可能包含額外的除錯資訊。
- 效能、耗電及檔案大小不代表最終正式版本。
- 正式版本若更換套件名稱或簽署金鑰，可能需要先解除安裝 Debug 版本。

## 回報問題

回報時請附上以下資訊：

- 手機品牌與型號
- Android 版本
- APP 使用直式或橫向顯示
- 問題發生步驟
- 預期結果與實際結果
- 畫面截圖或錄影（如適用）

請透過 GitHub Issues 提交問題，並避免在截圖中包含個人或敏感資訊。
