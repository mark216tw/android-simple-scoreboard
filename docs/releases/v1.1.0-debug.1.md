# v1.1.0-debug.1 - Debug 測試版

> [!WARNING]
> 此 APK 為 **Debug 測試版本**，不是正式發行版本。僅供功能測試與意見回饋，未使用正式 Release 金鑰簽署。

## 本次更新

- 新增 `+2` 與 `+3` 快速計分按鈕，畫面順序為 `−1`、`+3`、`+2`
- 新增較清楚的短促計分提示音
- 設定新增計分音效開關，預設開啟
- 新增本次 APP 執行期間的計分紀錄
- 計分紀錄包含隊名、加減分、調整後分數與時間
- 重設本場時同步清除計分紀錄
- 新增自訂主題色相滑桿與即時預覽
- 客隊自訂色會自動使用主隊色的互補色
- 交換隊伍時同步交換名稱、比分、局數及顏色
- 改善預設及自訂主題的文字對比
- 更新繁體中文使用說明與版本紀錄

## 計分紀錄說明

計分紀錄只保留於本次 APP 執行期間。手機旋轉時會保留，但 APP 程序被關閉或系統回收後會清除。比分、局數、團隊名稱及 APP 設定仍會自動保存。

## 安裝提醒

- APK 使用 Android Debug 簽章。
- Android 可能要求允許瀏覽器或檔案管理器安裝未知應用程式。
- 未來正式版本若使用不同套件名稱或簽署金鑰，可能需要先解除安裝本 Debug 版本。
- 此版本尚未完成完整的多品牌實機相容性測試。
