# v1.1.0-prerelease - 測試發行版

> [!WARNING]
> 此 APK 是 **Prerelease 測試版本**，不是正式發行版本。雖然已啟用 R8 與資源壓縮，仍使用 Android Debug 金鑰簽署，僅供測試與意見回饋。

## 本次更新

- 新增跟隨系統、鎖定直式及鎖定橫式三段循環切換
- 螢幕方向按鈕固定顯示自動旋轉圖示
- 每次切換方向後顯示目前狀態提示
- 新增沉浸式全螢幕模式
- 全螢幕時隱藏手機狀態列及底部導覽列，保留 APP 工具列
- 全螢幕按鈕會切換為退出圖示，可從同一位置恢復系統列
- 工具列調整為交換、螢幕方向、全螢幕及更多
- 計分紀錄、重設本場及 APP 設定移至更多選單
- 計分紀錄新增計分當下的局數快照
- 每隊新增獨立的分數歸零按鈕及短時間復原功能
- 每筆紀錄包含操作後的主客隊名稱、分數、局數與時間
- 支援複製全部紀錄及透過 Android 系統分享至其他 APP
- 計分紀錄可切換詳細或表格格式，表格包含主隊分數、客隊分數、局數與時間
- 複製與分享會依目前選擇輸出詳細文字或 Markdown 表格
- APP 圖示核心圖案等比例縮小 8%

## 安裝提醒

- 本版簽署憑證與 GitHub 上一個測試 APK 不同，Android 無法直接覆蓋安裝；請先解除安裝舊版。
- 解除安裝會清除舊版保存在裝置上的比分、隊名與 APP 設定。
- Android 可能要求允許瀏覽器或檔案管理器安裝未知應用程式。
- 未來正式版本若使用不同簽署金鑰，可能需要先解除安裝本測試版本。
- 此版本尚未完成完整的多品牌實機相容性測試。
